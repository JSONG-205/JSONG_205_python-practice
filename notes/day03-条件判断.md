## 核心概念

### 三种结构

```python
# 1️⃣ 单个 if
if 条件:
    条件成立时执行

# 2️⃣ if - else（二选一）
if 条件:
    成立时执行
else:
    不成立时执行

# 3️⃣ if - elif - else（多选一，最常用）
if 条件1:
    ...
elif 条件2:
    ...
elif 条件3:
    ...
else:
    ...
```

### 🔑 elif 的精髓（最重要）

> **从上往下挨个判断，命中第一个成立的就执行，然后跳出整个结构。**

由此推出两条关键结论：

**结论 1：条件必须从严格写到宽松**

```python
if score >= 60:      # ❌ 先写宽松的，95 分会被判成"及格"就跳出
    ...
elif score >= 90:    # 永远轮不到
    ...
```

**结论 2：每个分支只需要管上界**

```python
if bmi < 18.5:
    level = "偏瘦"
elif bmi < 24:       # 能走到这，说明 bmi >= 18.5 已成立，不用再写
    level = "正常"
elif bmi < 28:       # 能走到这，说明 bmi >= 24 已成立
    level = "偏胖"
else:                # 能走到这，说明 bmi >= 28
    level = "肥胖"
```

## 语法速查

### 三条铁律

**铁律 1：冒号 + 缩进**

```python
if age >= 18:
    print("成年")        # ← 缩进 4 格，属于 if
print("结束")            # ← 没缩进，跳出 if 了
```

- `if` 行末尾**必须有英文冒号** `:`
- 内部代码**统一缩进 4 个空格**
- 缩进不一致 → `IndentationError`

**铁律 2：`=` 和 `==` 完全不同**

```python
age = 18        # 赋值：把 18 装进 age
age == 18       # 判断：age 是不是等于 18 → True/False
```

写 `if age = 18:` 会直接报错。

**铁律 3：比较运算符**

| 符号 | 含义 |
|---|---|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` `<` | 大于 / 小于 |
| `>=` `<=` | 大于等于 / 小于等于 |

### 逻辑运算符

| 符号 | 含义 | 例子 |
|---|---|---|
| `and` | 并且，两个都成立 | `age >= 18 and age <= 65` |
| `or` | 或者，任一成立 | `score < 0 or score > 100` |
| `not` | 取反 | `not (age >= 18)` |

**Python 独有的链式写法：**

```python
if 18 <= age <= 65:    # 等价于 age >= 18 and age <= 65
```

### 取余运算符（判奇偶）

```python
7 % 2   →  1      # 7 除以 2 余 1
8 % 2   →  0      # 8 除以 2 余 0
```

`num % 2 == 0` → 偶数（**0 也是偶数**）

## 今天的代码

**`bmi.py`（升级版，加体型分级）**

```python
height = float(input("请输入身高（米）："))
weight = float(input("请输入体重（公斤）："))
bmi = weight / (height ** 2)

if bmi < 18.5:
    level = "偏瘦"
elif bmi < 24:
    level = "正常"
elif bmi < 28:
    level = "偏胖"
else:
    level = "肥胖"

print(f"你的BMI为{bmi:.1f}，你属于{level}")
```

**`judge.py`** —— 两组独立判断

```python
num = int(input("请输入一个整数："))

# 第一组：正负零
if num > 0:
    print("这是正数")
elif num < 0:
    print("这是负数")
else:
    print("这是零")

# 第二组：奇偶
if num % 2 == 0:
    print("这是偶数")
else:
    print("这是奇数")
```

> ⚠️ **为什么是两组而不是一个长链？** 因为"正负"和"奇偶"是两件独立的事，都要判断。写成一个 if/elif 链，判断完正负就跳出了，奇偶永远不执行。

**`grade.py`** —— 先拦异常再做分级

```python
score = float(input("请输入成绩："))

if score < 0 or score > 100:      # 异常先拦
    level = "分数不合法"
elif score >= 90:
    level = "优秀"
elif score >= 80:
    level = "良好"
elif score >= 70:
    level = "中等"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"

print(f"你的成绩为{score:.0f}，等级为{level}")
```

> 🔑 **先拦截异常，再做正常分级**。如果先判 `>= 60`，那输入 120 会被判成"及格"，永远轮不到"不合法"。

## 踩坑记录

### 🐛 坑 1：恒假条件（今天最有价值的 bug）

```python
elif BMI < 27.9 and BMI > 27.9:    # ❌
```

**翻译**："BMI 小于 27.9 **并且**大于 27.9" —— 一个数能同时满足吗？**永远不能。**

**后果**：BMI 27.2 走到这行判定失败，滑到 `else` 被贴上"肥胖"标签。**程序不报错，但答案是错的。**

**正确写法**：

```python
elif BMI < 28:    # ✅ 只写上界
```

> ⚠️ **这类 bug 最阴险** —— 语法完全合法、运行不报错、输出看着正常，只有拿边界值测试才能发现。
> **教训：写完必须测边界值。**

### 🐛 坑 2：字符串内拼写错误不报错

```python
print(f"你的MBI为{bmi}")    # MBI 字母顺序反了
```

**原因**：引号内的任何内容，Python 都当普通文字原样打印，**不会帮你检查**。

**解法**：检查引号内文案；变量名保持小写统一。

### 🐛 坑 3：文件漏提交

GitHub 上看不到 `bmi_pro.py`，提交回显只有 2 个文件。

**解法**：
1. 提交后必跑 `git status` 确认
2. **留意 commit 回显里的文件数量** —— 说好交三个，只进来两个就是信号
