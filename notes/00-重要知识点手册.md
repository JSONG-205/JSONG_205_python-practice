## 二、Git 版本管理

| 知识点 | 要点 |
|---|---|
| 每天收工三连 | `git add .` → `git commit -m "描述"` → `git push` |
| 两个查看命令 | `git status` 看**现在**（有无未提交）；`git log --oneline` 看**过去**（提交历史） |

## 三、变量与数据类型

| 知识点 | 要点 |
|---|---|
| 变量本质 | 贴着标签的盒子。`=` 是"把右边装进左边"，不是数学的"等于" |
| 四种基本类型 | `str` 字符串（带引号）/ `int` 整数 / `float` 小数 / `bool` 真假 |

## 四、输入输出与格式化

| 知识点 | 要点 |

## 五、条件判断

| 知识点 | 要点 |
|---|---|
| `=` 与 `==` | `=` 是赋值，`==` 是比较。搞混是高频错误 |
| 执行规则 | if/elif/else **从上往下，命中一个就跳出**，后面不再看 |
| **条件从严格到宽松** | 范围小的写前面，范围大的写后面。写反了后面的分支永远走不到 |
| elif 只写上界 | 前面已经排除了小值，不用再写下界（写 `bmi < 28` 就够了） |
| **边界值必测** | 59/60、89/90 这种临界点最容易错，只测中间值（75）不够 |
| 逻辑运算符 | `and` 两边都真 / `or` 一边真 / `not` 取反 |

## 六、循环

| 知识点 | 要点 |
|---|---|
| **range 含头不含尾** | `range(1, 5)` 只有 1、2、3、4；`range(5)` 是 0~4 |
| for vs while | 知道跑几遍用 for；不知道跑几遍用 while |
| `while True` + break | 死循环必须靠 break 退出 |
| break vs continue | `break` 跳出**整个**循环；`continue` 跳过**本次**进下一次 |
| 嵌套循环 | **外层走一步，内层跑一圈** |
| **先判命中，再判次数** | 猜数字游戏：第 7 次猜中却被判"机会用完"，就是因为顺序写反了 |

## 七、列表 list

| 知识点 | 要点 |
|---|---|
| 下标从 0 开始 | 最大下标是 `len(lst)-1`；`-1` 是最后一个，`-2` 倒数第二个 |
| 切片含头不含尾 | `lst[1:3]` 取下标 1、2；`lst[:3]` 前三个；`lst[::-1]` 反转 |
| 增 | `append(x)` 末尾加；`insert(i, x)` 指定位置插 |
| 删 | `remove(x)` 删**第一个值**为 x 的；`pop(i)` 删**下标 i** 的并返回；`del lst[i]` |
| 查 | `len()` 个数、`x in lst` 在不在、`lst.count(x)` 出现几次、`lst.index(x)` 首次下标 |
| **`sorted()` vs `.sort()`** | `sorted(lst)` 返回**新列表**，原列表不变；`lst.sort()` 改**原列表**，返回 `None`。口诀：**sorted 有返回值要接，.sort() 没返回值别接** |
| 三种核心模式 | ① 筛选：空列表 + 循环 + `append` ② 计数：`count += 1` ③ **按下标修改：必须 `for i in range(len(lst))`** |
| ⚠️ 遍历中别改列表 | `for item in lst: item = 新值` 改的只是临时变量，列表不变 |

## 八、字典 dict 与集合 set

| 知识点 | 要点 |
|---|---|
| 一句话区分 | **列表靠数（下标），字典靠叫（键）** |
| **`[]` vs `get()`** | `d["不存在的键"]` 直接 **KeyError 崩掉**；`d.get("键")` 返回 `None`；`d.get("键", "默认值")` 给退路 |
| 增改删 | 增和改写法一样（看键以前有没有）；删用 `pop(键)` 或 `del d[键]`。**字典没有 append** |
| `in` 判断的是键 | `"name" in d` 判断键；想判断值用 `d.values()` |
| 遍历三种 | `.items()` 键+值（最常用）/ `.keys()` 键 / `.values()` 值 |
| **嵌套取值** | `d["a"]["b"]` —— 两个方括号**并排**，一层层剥。对应 JSON 对象 |
| 列表套字典 | 数据集标准形态，像 Excel 表格。取值 `students[1]["score"]` |
| 集合 set | 自动去重、**无序**（不能 `s[0]`）。去重组合：`list(set(旧列表))` |
| 集合运算 | `a \| b` 并集 / `a & b` 交集 / `a - b` 差集 |
| 元组 tuple | 不可变（`t[0] = x` 报错），用于坐标、日期这类不该改的数据 |
| 三种核心模式 | ① **打擂台**找最大：`top = data[0]`，循环比 `> top[...]` ② 计数器 ③ 筛选收集 |

## 九、函数

| 知识点 | 要点 |
|---|---|
| 定义 | `def 函数名(参数):` → 缩进 4 空格 → `return 返回值` |
| **return vs print** | `return` 把值交回（能接着用）；`print` 只显示（值是 `None`）。**核心原则：函数负责算，主流程负责打印**。不确定就用 return |
| 默认参数 | `def f(a, b=10)` —— **有默认值的参数必须放后面**，否则 SyntaxError |
| 作用域 | 函数是独立小房间：外面的变量里面能读；里面改同名变量是新建，不影响外面 |
| 判空列表 | `if not lst:` 比 `if len(lst) == 0:` 更简洁（Python 里"空的东西 = 假"） |
| 主动报错 | `raise ValueError("空列表没有最大值")` —— 比让程序报 IndexError 更清晰 |
| 入口保护 | `if __name__ == "__main__":` 只有自己运行才执行，被别人 import 时不执行 |
| 三个重构原则 | ① 一个函数只干一件事 ② 数据通过**参数**传进来，不读全局变量 ③ 用 return 交回结果 |
| 什么时候抽函数 | 同一段代码写 2 遍以上、或一段逻辑能独立描述 → 抽；只写一次很简单 → 不抽 |

## 十、字符串

| 知识点 | 要点 |
|---|---|
| 索引切片 | 和列表**完全一样**：`s[0]`、`s[-1]`、`s[1:4]`、`s[::-1]` 反转 |
| **字符串不可变** | `s[0] = "J"` 报 TypeError。**所有字符串方法都返回新字符串，原字符串不动**，必须用变量接：`s = s.replace(...)` |
| 大小写 | `s.upper()` / `s.lower()`。用于命令输入不区分大小写 |
| 去空白 | `s.strip()` 去两端 / `lstrip()` 左 / `rstrip()` 右。常用 `input().strip()` |
| 拆分 | `s.split(",")` 按逗号拆成列表；`s.split()` 默认按空格拆 |
| 合并 | `",".join(列表)` —— **分隔符在前，列表在后**。写反成 `lst.join(",")` 会报错 |
| 替换 | `s.replace("旧", "新")`，可用来去空格：`s.replace(" ", "")` |
| 开头结尾 | `s.startswith("x")` / `s.endswith(".py")` 返回 True/False |
| 查找计数 | `s.find("x")` 返回下标，**找不到返回 -1**；`s.index("x")` 找不到**报错**；`s.count("x")` 找不到返回 **0** |
| **`if s.find("e"):` 是错的** | 因为 `-1` 也是真值，会把"没找到"误判成"找到了"。要用 `if "e" in s:` 或 `!= -1` |
| f-string 进阶 | `f"{x:.2f}"` 2位小数 / `f"{x:,}"` 千分位 / `f"{x:.1%}"` 百分比 / `f"{x:^10}"` 居中宽10 |
| **格式说明符的点** | **精度前面必须有点**（`.2f`、`.1%`），**宽度不需要点**（`10`、`^10`）。`f"{x:.2}"` 是"2 位有效数字"不是小数，会输出科学计数法 |

## 十一、文件读写

| 知识点 | 要点 |
|---|---|
| 一句话本质 | 内存里的数据程序一关就没，写文件才能留住。**大数据的核心工作：读数据 → 处理 → 写结果** |
| 标准写法 | `with open("文件名", "模式", encoding="utf-8") as f:` —— **文件操作一律用 `with`**，离开代码块自动关闭 |
| 三个模式 | `"r"` 读（默认，文件不存在报错）/ `"w"` 写（**打开就清空**，危险）/ `"a"` 追加（末尾续写，不删原内容） |
| `encoding="utf-8"` | **涉及中文必须加**。Windows 默认 GBK，换机器读会乱码 |
| 三种读法 | `f.read()` 整块字符串（小文件）/ `f.readlines()` 列表，**元素带 `\n`** / `for line in f` 逐行（**大文件推荐**） |
| 两种写法 | `f.write("内容\n")` 写字符串 / `f.writelines(lst)` 写列表。**都不会自动加 `\n`**，得自己写 |
| `write()` 只收字符串 | `f.write(85)` 报 TypeError，要 `f.write(f"{85}\n")` |
| `\n` 要写在引号里 | `f.write(x\n)` 是 SyntaxError，转义字符必须在字符串内：`f.write(f"{x}\n")` |
| **文件指针** | 读一次往前走一次，不回头。**一个 `with` 里读操作只做一次**，想再读就重开文件，或 `f.seek(0)` 回开头 |
| 读写不能混 | `"a"` / `"w"` 模式的文件不可读，硬读报 `io.UnsupportedOperation: not readable`。读写分开两个 `with` |
| `enumerate(lst, start=1)` | 遍历带序号，不用手写 `count += 1`。每次产出 `(序号, 元素)` 元组，`for i, x in ...` 拆包 |
| 同时开两个文件 | `with open(源) as f_in, open(目标, "w") as f_out:` —— 文件复制、格式转换的标准写法 |
| **内置名不能当变量名** | `str`、`int`、`list`、`sum`、`max`、`min` 都是内置的，被覆盖后原功能就没了 |

## 十二、JSON 数据

| 知识点 | 要点 |
|---|---|
| 为什么用 JSON | `str(dict)` 出来是单引号，别的语言读不了。JSON 是**跨语言标准格式**，Python/Java/JS 都能读 |
| 四兄弟口诀 | **有 `s` 跟字符串，无 `s` 跟文件；`d` 开头是写，`l` 开头是读** |
| 四兄弟对照 | `dumps(对象)→字符串` / `dump(对象, 文件)→None` / `loads(字符串)→字典` / `load(文件)→字典` |
| 两种引号的区别 | JSON 字符串里是**双引号**（`"name"`）；`loads` 解析后 `print` 出来是**单引号**（`'name'`）——前者是 JSON，后者是 Python 字典。同一份数据不同阶段长相不同 |
| `ensure_ascii=False` | **中文场景必须加**，否则输出 `\u5f20\u4e09` 这种转义 |
| `indent=2` | 格式化缩进，不加全挤一行。写给人看的文件加上 |
| JSON 只有 6 种类型 | object↔dict / array↔list / string↔str / number↔int,float / boolean↔bool / null↔None |
| 不能直接转的 | `set`（先 `list()`）、`datetime`（先 `str()`）、自定义类（先转 dict）。`tuple` 会变 array，读回来是 list |
| JSON 文件必须用 `"w"` | 用 `"a"` 追加会让文件格式不合法（多个对象拼在一起不是合法 JSON） |

## 十三、异常与调试

| 知识点 | 要点 |
|---|---|
| 一句话本质 | 程序不能因为一个错误整个崩掉。**`try` 包危险代码，`except` 接错误，`finally` 做收尾** |
| 基础结构 | `try:` 危险操作 / `except 异常类型:` 处理代码。`try` 里正常就跳过 `except`；出错就**跳过剩余代码**跳到 `except` |
| 常见异常类型 | `TypeError` 类型不对 / `ValueError` 值不对 / `NameError` 变量不存在 / `IndexError` 下标越界 / `KeyError` 键不存在 / `AttributeError` 属性方法不存在 / `ZeroDivisionError` 除以 0 / `FileNotFoundError` 文件不存在 |
| **类型必须对得上** | `except` 写的类型要和实际抛出的**完全一致**，写错就接不住、照样崩。`int("abc")` 抛 `ValueError`，写 `except ZeroDivisionError` 没用 |
| 多个 `except` | 从上到下匹配，**命中第一个就跳出去**。只捕获一种会漏，另一种照样崩 |
| 一个 `except` 抓多种 | `except (ValueError, ZeroDivisionError):` —— 用元组把几种写一起 |
| `finally` | **不管出不出错都执行**。用于关文件、释放资源、打日志 |
| ⚠️ `finally` 里别 `return` | `finally` 里的 `return` 会**覆盖** `try` 里的 `return`。只做收尾，不返回 |
| `except Exception as e` | `Exception` 是所有异常的父类，能兜住全部，`e` 是错误对象。**正式项目不推荐**（吞错误不好排查），只在调试用 |
| **看报错三步** | ① **最后一行** = 什么错 ② **倒数二三行** = 哪一行 ③ 跳过去改。**从下往上读**，第一行 `Traceback` 没信息 |
| `try` 范围 | **只包可能出错的部分**。包太小接不住，包太大把不该捕的也捕了 |
| 调试 vs 生产 | 调试时用 `Exception` 兜底快速定位；正式代码按具体类型精确捕获 |

## 十四、模块与包

| 知识点 | 要点 |
|---|---|
| 一句话本质 | **模块 = 一个 `.py` 文件**。标准库里几百个模块，你写的文件也是模块，可以被 import |
| 三种 import | `import math` 用 `math.xxx`（**推荐**，来源清晰）/ `from math import sqrt` 直接用 `sqrt` / `import math as m` 用 `m.xxx` |
| `math` 数学 | `pi` 圆周率 / `sqrt(x)` 平方根 / `pow(a,b)` 次方（**返回浮点**）/ `ceil` 向上取整 / `floor` 向下取整 |
| `os` 系统 | `getcwd()` 当前目录 / `listdir(".")` 列目录 / `path.exists(f)` 是否存在 / `path.join("a","b")` 拼路径（**跨平台**，别手工拼 `/`） |
| `datetime` 时间 | `datetime.now()` 当前时刻 / `date.today()` 今天 / `+ timedelta(days=7)` 日期加减 / `.strftime("%Y-%m-%d")` 格式化 |
| `random` 随机 | `randint(1,100)` 随机整数 / `choice(lst)` 随机取一个 / `sample(lst,3)` 抽 3 个不重复 / `shuffle(lst)` **原地打乱、无返回值** |
| `pip` 常用命令 | `pip install 库名` / `pip install 库名==版本` / `pip list` 看已装 / `pip uninstall 库名` 卸载 |
| 国内加速源 | `pip install 库名 -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `requests` 调 API | `requests.get(url)` → `response.status_code` 状态码 / `response.json()` 把 JSON 转成字典 → `data["字段名"]` 取值 |
| ⚠️ **解释器必须和 pip 一致** | pip 装到 Python A、运行时用 Python B → 必然 `ModuleNotFoundError`。**先看运行输出第一行是哪个 Python**，再决定往哪装 |
| ⚠️ **系统托管的 Python 装不了包** | MSYS2、部分 Linux 自带的 Python 受 PEP 668 保护，pip 会拒绝：`error: externally-managed-environment`。解法是换官方 Python，或建虚拟环境 |
| 标准库 vs 第三方 | 标准库（`math` `os` `datetime` `random` `json`）开箱即用；第三方（`requests` `pandas`）必须先 `pip install` |

## 十五、反复踩的坑（重点盯）

| 坑 | 正确做法 | 已踩次数 |
|---|---|---|
| **`for i in len(s)`** | `for` 只跟**容器**，不跟数字。要下标用 `for i in range(len(s))`，不然直接 `for item in s` | **2 次**（Day6、Day9） |
| **同一个 `with` 块里连续读多次** | 文件指针读一次走一次，第二次读拿到空。要么每个读操作独立 `with`，要么 `f.seek(0)` 回开头 | **2 次**（Day10 练习2、练习5） |
| **`dump` / `load` 参数写错** | `dump` 要**两个**参数（对象 + 文件）；`load` 只要**一个**（文件对象），返回值用 `=` 接 | 2 次（Day11 坑1、坑2） |
| **内置名当变量名** | `str` / `int` / `list` / `sum` / `max` / `min` 都不能当变量名，会把内置功能覆盖掉。换 `lines_out` 这类名字 | 1 次 |
| **字典用 `.key` 取值** | 字典没有属性，只能 `d["key"]`。用 `.` 会报 AttributeError | 2 次（Day6、Day11） |
| `"w"` 模式打开两次 | `"w"` 打开就清空，两次只剩最后一次内容。想保留原内容用 `"a"`，或合并成一次写 | 1 次 |
| `\n` 写在引号外 | 转义字符必须在字符串内：`f.write(f"{x}\n")` | 1 次 |
| 单复数变量 / 文件名混淆 | `student`（单个字典）vs `students`（列表）；`student.json` vs `students.json`。写错不报错，但内容错 | 1 次 |
| 中文输入法混进代码 | 全角 `（）` `：` `＝` 会让 Python 报 SyntaxError。写代码前先看输入法 | 1 次 |
| 字符串方法没接返回值 | `s.replace(...)` 单独一行等于白调用，必须 `s = s.replace(...)` | 1 次 |
| 多步操作心算跳步 | 列表连续增删时，每一步都在纸上写下当前状态再算下一步 | 1 次 |
| `.gitignore` 中文注释乱码 | 编码不一致导致，功能无影响但不美观 | 1 次 |
| commit 号看错 | `a1d43ac` 里的 `1` 别看成字母 `l`，从 `git log` 直接复制 | 1 次 |
| **`except` 类型写错，接不住** | `except` 的类型要和实际抛出的**完全一致**。`int("abc")` 抛的是 `ValueError`，写 `except ZeroDivisionError` 就白写，照样崩 | 1 次（Day12） |
| **`finally` 里写 `return`** | `finally` 的 `return` 会**覆盖** `try` 里的返回值。`finally` 只做收尾（关文件、打日志），不要 `return` | 1 次（Day12） |
| **报错只读第一行** | `Traceback (most recent call last):` 这行没信息。要从**下往上**读：最后一行是什么错，倒数二三行是哪一行 | 1 次（Day12） |
| **pip 装的库和运行的解释器不是同一个** | 在 Python A 里 `pip install`、却用 Python B 跑 → `ModuleNotFoundError`。**先看运行输出第一行的 Python 路径**，认准那一个再装 | 1 次（Day13） |
| **`random.shuffle()` 当成有返回值** | 它是**原地打乱**，返回 `None`。`new = random.shuffle(lst)` 拿到的只有 `None`，原列表才被打乱 | 1 次（Day13） |
| **`math.pow` 与内置 `pow` 返回类型不同** | `pow(2,10)` 得整数 `1024`；`math.pow(2,10)` 得浮点 `1024.0`。要求整数结果就别用 `math.pow` | 1 次（Day13） |

## 十六、贯穿全程的方法论

| 原则 | 说明 |
|---|---|
| **三种核心模式** | 筛选收集、计数器、打擂台 —— pandas 的 groupby、SQL 的 WHERE、Spark 的 filter 本质都是它们 |
| **不确定就用安全写法** | 取字典值不确定键在不在 → `get()`；结果后面还要用 → `return` |
| **边界值必测** | 59/60、0/-1、空列表、第一次/最后一次 |
| **报错不可怕** | 三段式看：报错原文 → 原因 → 解法。先确认"代码没丢"，再找原因。**读报错从下往上**：最后一行是错误类型，倒数二三行是行号 |
| **异常处理要"精确"不要"兜底"** | `try` 只包可能出错的部分，`except` 写具体的异常类型。`except Exception` 是调试工具，正式代码里用它等于把所有错误藏起来，出问题更难查 |
| **输出由代码决定，不由语感决定** | `f"{greeting}，{name}"` 输出"你好，张三"，不是"张三你好" |
| **一步一步来** | 多步操作心算容易跳步出错，把中间状态写下来 |
| **数据落盘才算真的存在** | 内存里的列表、字典关掉程序就没了，要留存的结果必须写进文件 |
| **破坏性操作先想清楚** | `"w"` 一开就清空，误用一次原数据全没。写模式前先问自己：这次是要覆盖还是要追加 |
| **分清数据在不同阶段的样子** | 同一份数据，Python 里是单引号，JSON 里是双引号，打印出来又不一样。看到"长得不像"先想是哪一层，别急着当 bug 改 |
| **标准格式优先于自定义** | 存数据用 JSON 而不是 `str(dict)`，因为前者跨语言、跨工具，十年后还能读 |
| **出问题先问「用的是哪个 Python」** | 报 `ModuleNotFoundError`、装包不生效、"明明装了却找不到"——**八成是解释器不对，不是代码错**。第一件事看运行输出第一行的 Python 路径 |
| **标准库优先，别造轮子** | 动手前先想"标准库有没有现成的"。`math` `os` `datetime` `random` `json` 覆盖了大量日常需求 |
